# Product generation: iPhone variants

All images were made with the built-in ImageGen tool without source images, with transparent background enabled. One independently generated image per model and finish; they are illustrative product renders, not official product photos. The source PNGs remain in the local ImageGen library and the project uses alpha-preserving, resized WebP files.

Shared prompt: `Use case: product-mockup. Create an original photorealistic high-end studio product render for a white mobile catalog. Subject: one [model and camera geometry]; visible body finish must be unmistakably [finish]. Show a tasteful three-quarter rear view with rear cameras clearly visible, accurately proportioned full device centered with ample margin, matte glass and precision machined metal, soft controlled studio lighting. Genuine transparent alpha background, clean antialiased edges; no surface, no floor or cast shadows, no text, labels, or watermark. Newly generated product illustration, not an Apple photo.`

Model-specific wording: iPhone 18 Pro / Pro Max: three large cameras in a raised block; iPhone Duo: partially opened book-like foldable, dual camera; iPhone Air: slim body, single rear lens in an elongated bar; iPhone 17 and 16: two vertically aligned lenses; iPhone 17e: single rear lens. Color names and output paths appear in generated-phones.json. The first black Pro Max sample used the same requirements with equivalent prose.

ImageGen can invent physical details; generation does not establish a product's exact real appearance. Inspect the color, object and alpha edges on white before publishing.
