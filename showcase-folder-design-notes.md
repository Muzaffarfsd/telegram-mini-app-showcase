# Витрина — папки магазинов

Задача: полностью новая витрина по референсу пользователя от 7 ноября 2026. Светлая мобильная сетка, узнаваемые папки с бумажными вкладышами и отдельным стикером для каждого демо; акцент на форме и узнаваемости вместо прежних карточек и иллюстраций. Основа: F-20261107-004 (избегать конкретной отвергнутой мягкой серии), F-20261107-002 (предметные детали), P-21 (однострочная дизайн-типографика), прямой текущий образец. Проверить видимые папки, читаемость, фильтры и переходы на мобильных размерах и без горизонтального переполнения.
