# Apple Store — дополнительные ракурсы наушников и HomeView

Сгенерировано встроенным ImageGen на прозрачном фоне. Для каждого из 11 сочетаний сделан отдельный вызов. В качестве визуального ориентира использовано соответствующее ранее сгенерированное изображение из этого проекта; фотографии Apple не использовались. Выходные WebP находятся в `client/public/apple-store/generated/`, сопоставление моделей и цветов — в `scripts/generated-extra-wearables.json`.

Общий промпт: «Создай дополнительную оригинальную предметную иллюстрацию для каталога, используя нашу предыдущую генерацию только как ориентир модели и цвета. Новый ракурс три четверти, сохранить форму, материалы, оттенок и количество деталей. Предмет целиком в кадре, мягкий студийный свет, прозрачный альфа-канал, без сцены, пола, надписей или лишних предметов». Для AirPods 5 отдельно уточнены открытый футляр и наушники без силиконовых насадок; для AirPods Max — выбранный цвет и боковой ракурс; для HomeView — корпус, крепление или подставка выбранного цвета и выключенный экран.

Все 11 результатов просмотрены на контактном листе, проверены модель, цвет, наличие альфа-канала и прозрачность четырёх углов. Изображения являются генеративными интерпретациями и могут не совпадать с реальными изделиями в мелких деталях.
