## 1. Подготовка проекта

### 1.1 Проверка файлов

Убедитесь, что в корне проекта есть следующие файлы:

- ✅ `package.json` - с правильными скриптами build и start
- ✅ `railway.json` - конфигурация Railway
- ✅ `.gitignore` - игнорирование ненужных файлов
- ✅ `README.md` - описание проекта

### 1.2 Проверка скриптов

Откройте `package.json` и убедитесь, что есть:

```json
{
  "scripts": {
    "build": "vite build && esbuild server/index.ts --platform=node --packages=external --bundle --format=esm --outdir=dist",
    "start": "NODE_ENV=production node dist/index.js",
    "db:push": "drizzle-kit push"
  }
}
```

### 1.3 Проверка railway.json

Файл должен содержать:

```json
{
  "$schema": "https://railway.app/railway.schema.json",
  "build": {
    "builder": "NIXPACKS"
  },
  "deploy": {
    "numReplicas": 1,
    "restartPolicyType": "ON_FAILURE",
    "restartPolicyMaxRetries": 10
  }
}
```

## 2. Загрузка в GitHub

### Вариант А: Через интерфейс Replit (Рекомендуется)

#### Шаг 1: Откройте Git панель
1. В Replit нажмите на иконку **Git** в левой панели (иконка с ветками)
2. Если Git панель не открывается, убедитесь что проект сохранен

#### Шаг 2: Создайте репозиторий на GitHub
1. Откройте [github.com](https://github.com) в новой вкладке
2. Нажмите **"+"** → **"New repository"**
3. Заполните данные:
   - **Repository name**: `telegram-mini-app-showcase` (или ваше название)
   - **Description**: `Telegram Mini App Showcase для бизнеса`
   - **Visibility**: Public или Private (на ваш выбор)
   - ⚠️ **НЕ СТАВЬТЕ галочку** "Initialize this repository with a README"
4. Нажмите **"Create repository"**

#### Шаг 3: Подключите GitHub к Replit
1. В Git панели Replit нажмите **"Connect to GitHub"**
2. Авторизуйтесь в GitHub (если требуется)
3. Выберите ваш новый репозиторий из списка
4. Нажмите **"Connect"**

#### Шаг 4: Сделайте первый коммит
1. В Git панели вы увидите список измененных файлов
2. Нажмите **"Stage all"** (добавить все файлы)
3. В поле "Commit message" введите: `Initial commit - Telegram Mini App`
4. Нажмите **"Commit & push"**

✅ **Готово!** Код загружен в GitHub.

---

### Вариант Б: Через командную строку (Альтернатива)

#### Шаг 1: Создайте репозиторий на GitHub
(См. Вариант А, Шаг 2)

#### Шаг 2: Получите Personal Access Token
1. На GitHub: **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)**
2. Нажмите **"Generate new token (classic)"**
3. Дайте название: `Replit Deployment`
4. Выберите права: `repo` (полный доступ к репозиториям)
5. Нажмите **"Generate token"**
6. **Скопируйте токен** (он больше не покажется!)

#### Шаг 3: Настройте Git в Replit Shell
```bash
# Инициализируйте Git (если еще не инициализирован)
git init

# Добавьте все файлы
git add .

# Сделайте первый коммит
git commit -m "Initial commit - Telegram Mini App"

# Добавьте удаленный репозиторий
# Замените YOUR_USERNAME и YOUR_REPO на свои данные
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git

# Отправьте код (используйте токен вместо пароля)
git push -u origin main
```

При запросе пароля введите ваш **Personal Access Token**.

✅ **Готово!** Код загружен в GitHub.

## 3. Настройка Railway

### Шаг 1: Регистрация на Railway
1. Откройте [railway.app](https://railway.app)
2. Нажмите **"Login"** или **"Start a New Project"**
3. Войдите через **GitHub** (это важно для связи с репозиторием)

### Шаг 2: Создайте новый проект
1. На главной странице Railway нажмите **"New Project"**
2. Выберите **"Deploy from GitHub repo"**
3. **Первый раз**: Railway попросит доступ к вашим репозиториям
   - Нажмите **"Configure GitHub App"**
   - Выберите **"Only select repositories"**
   - Выберите ваш репозиторий `telegram-mini-app-showcase`
   - Нажмите **"Install & Authorize"**
4. Теперь выберите ваш репозиторий из списка
5. Railway автоматически начнет деплой

### Шаг 3: Дождитесь первой сборки
1. Railway начнет устанавливать зависимости и собирать проект
2. **Первая сборка займет 3-5 минут**
3. Вы увидите логи в реальном времени
4. ⚠️ **Сборка может упасть** - это нормально, нужно настроить переменные окружения

## 4. Настройка PostgreSQL

### Шаг 1: Добавьте PostgreSQL в проект
1. В вашем проекте Railway нажмите **"+ New"** (плюс)
2. Выберите **"Database"** → **"Add PostgreSQL"**
3. Railway автоматически создаст базу данных
4. Подождите 30-60 секунд пока база данных создастся

### Шаг 2: Подключите базу данных к сервису
1. Railway **автоматически** создаст переменную `DATABASE_URL`
2. Вы можете проверить это:
   - Нажмите на ваш сервис (не на PostgreSQL)
   - Перейдите во вкладку **"Variables"**
   - Вы должны увидеть `DATABASE_URL` со значением (скрыто)

✅ **База данных подключена!**

## 5. Переменные окружения

### Шаг 1: Откройте Variables
1. Нажмите на ваш **основной сервис** (не PostgreSQL)
2. Перейдите во вкладку **"Variables"**
3. Нажмите **"+ New Variable"**

### Шаг 2: Добавьте необходимые переменные

Добавьте следующие переменные **по одной**:

#### 🔑 TELEGRAM_BOT_TOKEN
```
Variable Name: TELEGRAM_BOT_TOKEN
Value: YOUR_TELEGRAM_BOT_TOKEN
```
(Ваш токен бота)

#### 🔗 DATABASE_URL
⚠️ **Эта переменная уже должна существовать!** Railway добавил её автоматически.
Если её нет - Railway автоматически свяжет PostgreSQL с сервисом.

#### 🌍 NODE_ENV
```
Variable Name: NODE_ENV
Value: production
```

#### 📦 PORT (опционально)
Railway автоматически установит PORT, но можно добавить:
```
Variable Name: PORT
Value: 5000
```

### Шаг 3: Сохраните переменные
1. После добавления всех переменных нажмите **"Deploy"** (если потребуется)
2. Railway автоматически **перезапустит** ваш сервис с новыми переменными

## 6. Настройка Telegram Bot

### Шаг 1: Получите URL вашего приложения
1. В Railway откройте ваш сервис
2. Перейдите во вкладку **"Settings"**
3. Найдите раздел **"Domains"**
4. Нажмите **"Generate Domain"**
5. Railway создаст домен вида: `your-app-name.up.railway.app`
6. **Скопируйте этот URL!**

### Шаг 2: Настройте Telegram Webhook
1. Откройте браузер и перейдите по адресу:
```
https://api.telegram.org/botYOUR_TELEGRAM_BOT_TOKEN/setWebhook?url=https://your-app-name.up.railway.app/api/telegram/webhook
```

Замените:
- `YOUR_TELEGRAM_BOT_TOKEN` - на ваш токен бота
- `your-app-name.up.railway.app` - на ваш домен Railway

2. Вы должны увидеть ответ:
```json
{
  "ok": true,
  "result": true,
  "description": "Webhook was set"
}
```

✅ **Webhook настроен!**

### Шаг 3: Проверьте Webhook
```
https://api.telegram.org/botYOUR_TELEGRAM_BOT_TOKEN/getWebhookInfo
```

Вы должны увидеть:
```json
{
  "ok": true,
  "result": {
    "url": "https://your-app-name.up.railway.app/api/telegram/webhook",
    "has_custom_certificate": false,
    "pending_update_count": 0
  }
}
```

### Шаг 4: Настройте Mini App URL в BotFather
1. Откройте Telegram и найдите **@BotFather**
2. Отправьте `/mybots`
3. Выберите вашего бота
4. Нажмите **"Bot Settings"** → **"Menu Button"**
5. Выберите **"Configure Menu Button"**
6. Введите **URL вашего приложения**:
```
https://your-app-name.up.railway.app
```
7. Введите текст кнопки (например: "Открыть приложение" или "Open App")

✅ **Mini App настроен!**

## 🐛 Решение проблем

### Проблема: Сервис не запускается

**Решение:**
1. Проверьте логи в Railway → Deployments → последний деплой
2. Убедитесь что все переменные окружения установлены
3. Проверьте что `DATABASE_URL` существует
4. Проверьте что скрипт `start` правильный в `package.json`

### Проблема: Telegram webhook не работает

**Решение:**
1. Проверьте что URL доступен (откройте в браузере)
2. URL должен быть **HTTPS** (Railway всегда дает HTTPS)
3. Переустановите webhook:
   ```
   https://api.telegram.org/bot<TOKEN>/setWebhook?url=<URL>/api/telegram/webhook
   ```
4. Проверьте логи сервера на ошибки

### Проблема: База данных не подключается

**Решение:**
1. Убедитесь что PostgreSQL сервис **Active**
2. Проверьте что `DATABASE_URL` присутствует в переменных
3. Railway автоматически связывает сервисы
4. Если нет - удалите и пересоздайте PostgreSQL

### Проблема: Приложение медленно загружается

**Решение:**
1. Проверьте регион Railway (должен быть близко к вашим пользователям)
2. Убедитесь что видео оптимизированы
3. Проверьте размер bundle в логах сборки

### Проблема: Изменения не применяются

**Решение:**
1. Убедитесь что вы сделали `git push`
2. Проверьте что Railway запустил новый деплой
3. Очистите кеш браузера / Telegram (закройте и откройте бота)
